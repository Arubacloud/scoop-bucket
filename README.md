# Scoop Bucket — Aruba Cloud CLI

This is the official [Scoop](https://scoop.sh) bucket for the [Aruba Cloud CLI](https://github.com/Arubacloud/acloud-cli).

## Install

```powershell
scoop bucket add arubacloud https://github.com/Arubacloud/scoop-bucket
scoop install acloud
```

## Upgrade

```powershell
scoop update acloud
```

The manifest `acloud.json` is updated automatically on every release of [acloud-cli](https://github.com/Arubacloud/acloud-cli).
